Play Integrity API Checker 状态说明

本文用于说明 Play Integrity API Checker 不同检测结果的常见含义，并提供基础排查思路。
内容仅供参考，不代表 Google 官方结论。

一、先看检测结果

Play Integrity API Checker 页面会显示 3 项检测结果：

  • ✅：该项检测通过
  • ❌：该项检测未通过

三项结果组合起来后，常见情况如下：

检测结果 基本含义 优先排查方向
✅✅✅ 三项检测全部通过 一般无需额外排查
✅✅❌ 两项通过，一项未通过 Keybox、安全补丁、设备参数及相关模块
❌✅❌ 一项通过，两项未通过 优先检查 Checker 的安装来源与签名
❌❌❌ 三项全部未通过 优先检查 Keybox 状态

注意： 检测结果只能作为当前环境的参考，不同设备、系统、ROM 及模块配置可能出现不同表现。

二、✅✅✅ 全部通过

这代表什么？

当检测结果为 ✅✅✅ 时，表示当前设备已通过 Play Integrity API Checker 的三项检测。

通常意味着：

  • 软件来源于 Google 官方渠道；
  • 安全补丁日期配置正常；
  • Play Integrity 相关模块已正确配置并生效；
  • Keybox（设备密钥）状态正常，未被吊销（Revoked）。

怎么理解？

一般来说，✅✅✅ 代表当前设备的完整性相关配置处于正常状态。

对于依赖 Play Integrity 验证的应用或游戏，这种状态通常更有利于正常通过相关检测。

三、✅✅❌ 两项通过，一项未通过

这代表什么？

当检测结果为 ✅✅❌ 时，表示三项检测中有两项通过，仍有一项未通过。

这种情况通常与以下因素有关：

  • Keybox（设备密钥）处于软吊销（Soft Revoke）状态；
  • 安全补丁日期配置不正确，或与当前环境不匹配；
  • 使用了修改机型、设备参数等相关模块，例如 Fingerprint、Device Props；
  • 多个相关模块之间存在配置冲突；
  • 某些模块未正确生效。

建议怎么排查？

建议按照以下顺序检查：

1. 检查 Keybox

确认当前使用的 Keybox 是否正常，是否存在 Soft Revoke 等情况。

2. 检查安全补丁日期

确认安全补丁日期配置是否正确，并检查是否与当前环境匹配。

3. 检查设备参数修改

回顾近期是否安装或启用了修改机型、Fingerprint、Device Props 等相关模块。

4. 排查模块冲突

如果同时使用了多个相关模块，可以暂时逐个禁用，以确认是否存在配置冲突。

四、❌✅❌ 一项通过，两项未通过

这代表什么？

当检测结果为 ❌✅❌ 时，表示只有一项检测通过，其余两项未通过。

根据常见情况，这种结果需要优先检查 Play Integrity API Checker 本身的安装来源。

常见原因

例如：

  • 从第三方应用商店下载了 Play Integrity API Checker；
  • 使用了他人分享的 APK；
  • APK 虽然最初来自 Google 官方渠道，但经过重新分发后无法正确通过来源验证；
  • 安装包经过重新签名、修改或其他处理。

建议怎么处理？

建议直接重新安装官方来源的版本：

  1. 卸载当前的 Play Integrity API Checker；
  2. 通过 Google 官方渠道重新下载安装；
  3. 尽量避免使用第三方应用商店或他人分享的 APK。

重新安装后，再重新执行一次检测。

五、❌❌❌ 全部失败

这代表什么？

当检测结果为 ❌❌❌ 时，通常与当前使用的 Keybox（设备密钥）被 Google 吊销（Revoked）有关。

在这种情况下，即使其他配置正常，也可能无法通过相关完整性检测。

建议怎么处理？

优先检查当前 Keybox 的状态。

如果确认 Keybox 已被吊销，可以更换可正常使用的 Keybox，再重新进行检测。

六、常见排查顺序

如果只是想快速定位问题，可以按照下面的顺序检查：

① 先看检测结果

确认当前属于：

✅✅✅ / ✅✅❌ / ❌✅❌ / ❌❌❌

② 再检查 Checker 来源

尤其是出现 ❌✅❌ 时，先确认 Play Integrity API Checker 是否来自 Google 官方渠道。

③ 检查 Keybox

出现 ✅✅❌ 或 ❌❌❌ 时，可以优先确认 Keybox 是否存在异常或吊销情况。

④ 检查安全补丁日期

确认安全补丁日期配置是否正确。

⑤ 检查设备参数及模块

回顾近期是否安装、修改了 Fingerprint、Device Props 或其他相关模块，并排查模块之间是否存在冲突。

七、注意事项

  • 本文仅用于说明 Play Integrity API Checker 的检测结果，不保证适用于所有设备和环境。
  • 不同品牌、系统版本、ROM 及模块配置，可能导致检测结果存在差异。
  • Google 可能调整 Play Integrity API 的检测规则，因此相同配置在不同时间也可能出现不同结果。
  • 本文内容主要根据用户反馈及实际使用情况整理，仅供参考，不代表 Google 官方结论。
