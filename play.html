Play Integrity API Checker 状态说明

← 返回 GitHub 下载文档

本文档用于说明 Play Integrity API Checker 不同检测结果的常见含义，仅供参考。

前言

Play Integrity API Checker 是用于检测设备 Play Integrity 状态的工具。

  • ✅：通过
  • ❌：未通过
✅✅✅   ✅✅❌   ❌✅❌   ❌❌❌

✅✅✅ 全部通过

  • 软件来源于 Google 官方渠道。
  • 安全补丁日期配置正确。
  • 模块配置正常。
  • Keybox 未被吊销。

✅✅❌ 两项通过，一项失败

  • Keybox 已被软吊销。
  • 安全补丁日期配置不正确。
  • 修改机型或设备参数模块导致异常。
  • 模块配置冲突。

❌✅❌ 一项通过，两项失败

  • 软件并非 Google 官方渠道获取。
  • 第三方应用商店下载。
  • 使用他人分享 APK 或重新签名。

❌❌❌ 全部失败

通常代表 Keybox 已被 Google 吊销（Revoked），建议更换可正常使用的 Keybox。

注意事项

  • 不同设备、ROM、模块配置可能存在差异。
  • Google 可能调整检测规则。
  • 以上经验均来源于用户反馈及实际使用情况整理，仅供参考，不代表官方结论。
